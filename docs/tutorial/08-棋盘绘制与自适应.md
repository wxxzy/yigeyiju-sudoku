# 08 · 棋盘绘制与自适应

> 本篇目标：理解 9×9 网格的绘制策略、候选数的排版技巧，以及 flash 动画的实现。

## 8.1 主题常量集中管理

`scripts/ui/theme.lua` 只有 69 行，但所有颜色、字号、尺寸都在这里：

```lua
local COLORS = {
    background = { 241, 245, 249, 255 },
    cellSelected = { 147, 197, 253, 255 },
    cellSameDigit = { 191, 219, 254, 255 },
    cellPeer = { 236, 243, 250, 255 },
    cellError = { 254, 202, 202, 255 },
    cellHint = { 253, 230, 138, 255 },
    digitGiven = { 30, 41, 59, 255 },
    digitUser = { 37, 99, 235, 255 },
    -- ...
}
local SIZE = { boardMax = 560, keypadHeight = 52, toolHeight = 42, hudHeight = 44 }
```

换皮只改这一个文件，逻辑层和控件层不写死颜色。配色数组是 RGBA 的 0–255 整数，符合 UrhoX UI 的约定。

## 8.2 网格绘制：只画右/下边框

`BoardView.new` 创建 81 个 `Panel + Label` 对。边框策略很讲究：

```lua
-- 每格只画右边和下边，避免相邻格双线叠加
if c < 9 then
    d.borderRight = (c % 3 == 0) and Theme.COLORS.gridBold or Theme.COLORS.gridThin
end
if r < 9 then
    d.borderBottom = (r % 3 == 0) and Theme.COLORS.gridBold or Theme.COLORS.gridThin
end
```

`c % 3 == 0` 和 `r % 3 == 0` 处用粗线画宫界。如果每格都画四条边，相邻边会叠成两条线，视觉上更粗且不均匀。

根节点设置：

```lua
self.root = UI.Panel {
    aspectRatio = 1,           -- 强制正方形
    maxWidth = Theme.SIZE.boardMax,
    overflow = "hidden",
    children = cells,
}
```

`aspectRatio = 1` 保证棋盘永远是正方形，`FitBoard` 只需要算一个边长。

## 8.3 候选数的 3×3 排版

一格最多 9 个候选数字，用 3 行×3 列的小字排布：

```lua
local function gridText(present)
    local lines = {}
    for r = 1, 3 do
        local parts = {}
        for c = 1, 3 do
            local n = (r - 1) * 3 + c
            parts[#parts + 1] = present(n) and tostring(n) or " "
        end
        lines[#lines + 1] = table.concat(parts)
    end
    return table.concat(lines, "\n")
end
```

**关键坑**：这些小字 Label 必须设 `textAlign = "left", paddingLeft = 5`，不能居中。

原因：居中对齐会吃掉行尾的空格，导致三行的列宽不一致，候选数看起来是歪的。左对齐 + 固定 padding 才能让三列严格对齐。

## 8.4 `refresh`：优先级决定视觉层次

每格背景的优先级（从高到低）：

```
提示高亮 > 选中 > 同数字 > 同行列宫 > 默认背景
wrong 标记覆盖以上所有 → 错误色
```

文字优先级：

```
确定数字 > 手写笔记 > 自动候选 > 空
```

```lua
function BoardView:refresh(board)
    for idx = 1, 81 do
        local bg = Theme.COLORS.background
        if isHint(idx) then bg = Theme.COLORS.cellHint
        elseif idx == board.selected then bg = Theme.COLORS.cellSelected
        elseif sameDigit(idx) then bg = Theme.COLORS.cellSameDigit
        elseif isPeerOfSelected(idx) then bg = Theme.COLORS.cellPeer end
        if board.wrong[idx] then bg = Theme.COLORS.cellError end
        -- 设置背景 ...
    end
    self:update(0)  -- 把进行中的动画盖回去
end
```

最后一行 `self:update(0)` 很重要：如果这时正好有 flash 动画在跑，refresh 会把背景重置成静态色，动画就闪一下消失了。调用 `update(0)` 立刻把动画颜色盖回去。

## 8.5 flash 动画

三种反馈色，时长不同：

```lua
function BoardView:flash(idx, kind)
    local colors = {
        place = { color = {96,165,250,255}, duration = 0.26 },  -- 蓝：落子
        error = { color = {248,113,113,255}, duration = 0.50 }, -- 红：错误
        hint  = { color = {251,191,36,255},  duration = 0.50 }, -- 琥珀：提示
    }
    self.anims_[idx] = { from = colors[kind].color, t = 0,
                         duration = colors[kind].duration, base = self.baseBg_[idx] }
end
```

动画插值用二次缓出：

```lua
function BoardView:update(dt)
    for idx, a in pairs(self.anims_) do
        a.t = a.t + dt
        local k = math.min(1, a.t / a.duration)
        local e = (1 - k) * (1 - k)  -- ease-out quad
        local color = mixColor(a.from, a.base, e)
        setCellBackground(idx, color)
        if k >= 1 then self.anims_[idx] = nil end
    end
end
```

`e = (1-k)²` 让颜色前段变化快、后段缓慢回落，手感更「脆」。

**踩过的坑**：最初落子 flash 用的是和「同数字高亮」相近的蓝色（191, 219, 254），结果满盘同数字高亮时完全看不出反馈。改成更饱和的 blue-400（96, 165, 250）后才明显。教训：**反馈色必须比常驻高亮色更饱和**，否则等于没有反馈。

## 8.6 尺寸设置与 nan 防御

```lua
function BoardView:setSize(px)
    if type(px) ~= "number" or tostring(px):find("nan") then return false end
    if px == self.size_ then return false end
    self.size_ = px
    self.root:SetStyle { width = px, height = px }
    return true
end
```

`GetComputedSize()` 首帧可能返回 nan。`nan ~= nan` 在 Lua 里为真，但 `nan > 0` 也可能为真，无法用比较判断。只能用 `tostring(px):find("nan")`。

`setSize` 返回布尔值表示「尺寸是否真的变了」，让 `FitBoard` 只在必要时打印日志、触发重排。

## 8.7 通关染色

```lua
function BoardView:markSolved()
    for idx = 1, 81 do
        setCellBackground(idx, Theme.COLORS.digitGivenBackground)
    end
    self.anims_ = {}
end
```

通关后把所有格子统一染成「给定数字」的背景色，视觉上表示「这一局已经定稿」。

## 8.8 本篇小结

- 只画右/下边框避免双线叠加；`aspectRatio=1` 保证正方形。
- 候选数用 3×3 排版，小字必须左对齐，否则列会歪。
- `refresh` 用优先级决定背景和文字层次，末尾 `update(0)` 保住动画。
- flash 缓出用 `(1-k)²`，反馈色必须比常驻高亮更饱和。
- 尺寸设置要防 nan，只能用字符串判定。
